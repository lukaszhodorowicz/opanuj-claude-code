# Opanuj Claude Code w godzinę

Darmowy kurs dla przedsiębiorców, marketerów i freelancerów. Po polsku, czyli za darmo, konkretnie i z rozmachem.

**[Zacznij kurs na claudecode.lukaszhodorowicz.pl](https://claudecode.lukaszhodorowicz.pl/)** · [Discord](https://discord.gg/GVyW87DEG3) · [Newsletter](https://lukaszhodorowicz.pl/smartletter/?utm_source=przewodnik-claude-code&utm_medium=github&utm_campaign=link-readme)

Samoaktualizujący się kurs Claude Code. Powstał na podstawie oficjalnej dokumentacji Anthropic. **Naucz się pracy w aplikacji Claude Code w wersji okienkowej.**

W kursie znajdziesz jasne instrukcje, quiz, fiszki do nauki i ćwiczenia, w których klikasz na stronie jak w prawdziwej aplikacji Claude.

Kurs pilnuje aktualności. Każde twierdzenie w lekcjach stoi na fakcie z oficjalnej dokumentacji Claude Code, z datą i wersją, przy której je sprawdzono. Gdy dokumentacja się zmienia, testy pokazują, co trzeba poprawić.

## Pytania i pomoc

Masz pytanie do lekcji albo chcesz pokazać swój efekt? Napisz na [Discordzie](https://discord.gg/GVyW87DEG3).

## Skąd treść

- Fakty: `dane/fakty.yaml`. Każdy ma źródło, datę sprawdzenia i wersję Claude Code.
- Mapa pokrycia: `dane/mapa-pokrycia.yaml`. Każda strona dokumentacji Claude Code ma tu przypisany moduł, powód pominięcia albo status „do ustalenia”.
- Migawka spisu dokumentacji: `dane/zrodla/llms.txt`.

## Fiszki w Anki

Talię składa jedno polecenie (potrzebny jest [uv](https://docs.astral.sh/uv/)):

```bash
uv run python -m narzedzia.fiszki_anki --wyjscie build/przewodnik-claude-code.apkg
```

Plik `build/przewodnik-claude-code.apkg` otwierasz w Anki. Ponowny import aktualizuje fiszki, zamiast je dublować.

## Dla opiekunów

- Witrynę kursu składa `uv run python -m narzedzia.witryna zbuduj` (wynik w `build/witryna`). Na GitHubie robi to proces `strona` po każdej zmianie na `main`.
- Spis lekcji i zapowiedzi w tym pliku odświeża `uv run python -m narzedzia.witryna readme`. Uruchom je po scaleniu nowych lekcji do `main`.
- Adres strony stoi w pliku `CNAME`.
